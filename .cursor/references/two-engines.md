# Two engines

```
                 CRYPTO CAPITAL
                      │
           ┌──────────┴──────────┐
           │                     │
        DEFI CORE            MEME / ALPHA
           │                     │
     this adventure         Pump.fun / memes
     compound 8–15%         asymmetric, optional
           │                     │
           └──────────┬──────────┘
                      ▼
                REINVEST WINNERS
                 into DeFi core
```

- **DeFi** protects and slowly grows the treasury. It is the path that can become $100/day **if capital is large**.
- **Meme/alpha** might accelerate the base. Assume it can go to **zero**. Never budget the 3–5 year clock on it.
- STATE.md tracks **DeFi treasury** only. Mention the other engine in notes, not in DeFi totals.
- Profits that actually land in a wallet and that the human decides to move across engines get a `/contribute` or `/update` with an explicit transfer note.
