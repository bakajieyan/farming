# Phases — capital ladder

Do not skip learning. Do not increase risk just because the book got larger.

| Level | Capital        | Goal                     | Portfolio APY aim | Behavior                                                         |
| ----- | -------------- | ------------------------ | ----------------- | ---------------------------------------------------------------- |
| 1     | $1k → $5k      | Learn without blowing up | 5–10%             | Solana + USDC/USDT + Kamino + conservative LP. **No leverage.**  |
| 2     | $5k → $25k     | Start optimizing         | 8–15%             | Add established Solana lending + selective LP / structured yield |
| 3     | $25k → $100k   | Real yield book          | 8–15%             | Active optimization, **diversify protocols**                     |
| 4     | $100k → $250k  | Yield becomes meaningful | 10–15%            | Treasury habits, protocol caps                                   |
| 5     | $250k → $300k+ | Approach $100/day        | ~12% sustainable  | Risk-adjusted yield > headline APY                               |

## Phase-up rule

Crossing a level is a **decision**. AskQuestion, then `/update` (DECISIONS + STATE phase field). Do not silently start looping because Level 2 said "optimize."
